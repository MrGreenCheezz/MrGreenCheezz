## 🔭 What I'm working on:
**[RatholeGUI](https://github.com/MrGreenCheezz/RatholeGUI)** — a Windows GUI for the Rathole reverse proxy. Generates `.toml` configs, deploys them over SSH/SFTP and controls the service on both hosts. Reads open ports straight from running processes via the Windows API, so you never have to look a port number up by hand.<br>
`C#` · `.NET 8` · `WinForms` · `SSH/SFTP` · `GitHub Actions CI`
